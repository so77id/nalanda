# Código ejecutable

Todo el código de esta página se compila y se ejecuta **en tu navegador**: no hay
servidor compilando nada. La primera ejecución de cada lenguaje descarga su
compilador, así que tarda; a partir de ahí es cuestión de segundos.

<Slide title="Java: edítalo y ejecútalo">
El lenguaje del curso. Cambia el arreglo, agrega un `System.out.println`, vuelve
a ejecutar. `Ctrl`/`Cmd` + `Enter` también ejecuta.

<CodeEditor
  language="java"
  defaultValue={`public class Main {
    public static void main(String[] args) {
        int[] nums = {5, 3, 8, 1};
        int max = nums[0];
        for (int x : nums) if (x > max) max = x;
        System.out.println("máximo = " + max);
    }
}
`}
/>
</Slide>

<Slide title="Leer sin ejecutar">
Cuando el código está para leerse y no para correrse, la variante `read` no
carga ningún compilador: no se descarga nada del toolchain hasta que ejecutas.

<CodeEditor
  language="java"
  variant="read"
  defaultValue={`public class Nodo {
    int valor;
    Nodo siguiente;
}
`}
/>
</Slide>

<Slide title="Con entrada estándar">
La variante `lab` agrega el panel de `stdin` y el selector de lenguaje, y puede
precalentar el runtime al abrir la página — acá lo dejamos apagado para no
descargar nada hasta que lo pidas. Lo que escribas abajo llega al programa como
entrada estándar.
