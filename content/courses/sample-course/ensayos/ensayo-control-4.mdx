# Ensayo del Control 4

El ensayo tiene la misma forma que el Control 4: tres preguntas de 20 puntos
para 90 minutos, sobre tablas hash, Set y Map, y grafos hasta la búsqueda en
profundidad y la búsqueda en anchura. Primero una de verdadero o falso
justificado, después el análisis de un código con un error y un requisito de
costo, y al final un problema que se modela como grafo y se implementa.

Conviene resolverlo completo y con el reloj corriendo antes de abrir la pauta:
la pauta trae, para cada parte, la respuesta esperada, las variantes que se
aceptan y los descuentos.
