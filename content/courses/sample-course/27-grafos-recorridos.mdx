# Grafos · Recorridos

Desde la entrada de un laberinto, ¿se llega a la salida? Y si se llega, ¿con
cuántos pasos, como mínimo? En una malla, ¿en qué orden se toman los ramos?
Ninguna de estas preguntas se responde mirando un vértice y sus vecinos: hay
que **recorrer** el grafo, de vecino en vecino, sin perderse en sus ciclos. El
orden en que se recorre decide qué pregunta responde.

{/* Maze — a maze as a grid of cells: `grid` is its rows, '#' a wall drawn solid and '.' a free cell. `numbers` writes each free cell's vertex, r · C + c, in its corner. `ends` ([entrance, exit], as vertices) draws an arrow into the entrance from the left and one out of the exit to the right, each named; both cells must sit on those borders. `ways` draws the implicit graph over it: a dot in each free cell and an edge to each free neighbour that shares a side. `tones` paints a free cell, keyed by its vertex: mark, keep or flag. `notes` writes a value in a free cell's lower right corner, keyed by its vertex: its distance, in the breadth-first search. `thread` is a list of vertices drawn as one line through their centres, in mark, ending in a dot: Teseo's thread. File-local: only the arc of the depth-first search draws a maze. */}

export function Maze({ grid, numbers = false, ends, ways = false, tones = {}, notes = {}, thread = [], caption, label }) {
  const cell = 40;
  const pad = 14;
  const side = ends ? 88 : pad;
  const rows = grid.length;
  const cols = grid[0].length;
  const gridW = cols * cell;
  const width = Math.max(gridW + 2 * side, caption ? caption.length * 6.6 + 24 : 0);
  const left = (width - gridW) / 2;
  const height = pad + rows * cell + (caption ? 34 : pad);
  const fill = { mark: 'var(--color-mark-soft)', keep: 'var(--color-keep-soft)', flag: 'var(--color-flag-soft)' };
  const stroke = { mark: 'var(--color-mark)', keep: 'var(--color-keep)', flag: 'var(--color-flag)' };
  const at = (v) => [left + (v % cols) * cell + cell / 2, pad + Math.floor(v / cols) * cell + cell / 2];
  const free = (r, c) => r >= 0 && r < rows && c >= 0 && c < cols && grid[r][c] === '.';
  const cells = [];
  for (let r = 0; r < rows; r++) {
    for (let c = 0; c < cols; c++) {
      const v = r * cols + c;
      const wall = grid[r][c] === '#';
      const tone = wall ? undefined : tones[v];
      cells.push(
        <g key={v}>
          <rect x={left + c * cell} y={pad + r * cell} width={cell} height={cell} style={{ fill: wall ? 'var(--color-ink-soft)' : 'var(--color-surface)', stroke: 'var(--color-ink-soft)' }} strokeWidth="1.4" />
          {tone ? <rect x={left + c * cell + 2} y={pad + r * cell + 2} width={cell - 4} height={cell - 4} style={{ fill: fill[tone], stroke: stroke[tone] }} strokeWidth="2.4" /> : null}
          {numbers && !wall ? <text x={left + c * cell + 4} y={pad + r * cell + 12} fontSize="10" fontWeight="700" fontFamily="var(--font-mono, monospace)" style={{ fill: 'var(--color-ink)' }}>{v}</text> : null}
          {!wall && notes[v] !== undefined ? <text x={left + (c + 1) * cell - 5} y={pad + (r + 1) * cell - 6} textAnchor="end" fontSize="13" fontWeight="700" style={{ fill: 'var(--color-ink)' }}>{notes[v]}</text> : null}
        </g>,
      );
    }
  }
  const graph = [];
  if (ways) {
    for (let r = 0; r < rows; r++) {
      for (let c = 0; c < cols; c++) {
        if (!free(r, c)) continue;
        for (const [dr, dc] of [[0, 1], [1, 0]]) {
          if (!free(r + dr, c + dc)) continue;
          const [x1, y1] = at(r * cols + c);
          const [x2, y2] = at((r + dr) * cols + c + dc);
          graph.push(<line key={`e${r},${c},${dr}`} x1={x1} y1={y1} x2={x2} y2={y2} style={{ stroke: 'var(--color-ink-soft)' }} strokeWidth="1.4" />);
        }
      }
    }
    for (let r = 0; r < rows; r++) {
      for (let c = 0; c < cols; c++) {
        if (!free(r, c)) continue;
        const [x, y] = at(r * cols + c);
        graph.push(<circle key={`v${r},${c}`} cx={x} cy={y} r="4.5" style={{ fill: 'var(--color-surface)', stroke: 'var(--color-ink-soft)' }} strokeWidth="1.4" />);
      }
    }
  }
  const points = thread.map((v) => at(v).join(',')).join(' ');
  const last = thread.length > 0 ? at(thread[thread.length - 1]) : null;
  const doors = [];
  if (ends) {
    const y0 = at(ends[0])[1];
    const y1 = at(ends[1])[1];
    const inX = left;
    const outX = left + gridW;
    doors.push(
      <g key="in">
        <line x1={inX - 26} y1={y0} x2={inX - 6} y2={y0} style={{ stroke: 'var(--color-ink)' }} strokeWidth="2" />
        <polygon points={`${inX - 2},${y0} ${inX - 9},${y0 - 4.5} ${inX - 9},${y0 + 4.5}`} style={{ fill: 'var(--color-ink)' }} />
        <text x={inX - 30} y={y0 + 4} textAnchor="end" fontSize="12" style={{ fill: 'var(--color-ink)' }}>entrada</text>
      </g>,
      <g key="out">
        <line x1={outX + 2} y1={y1} x2={outX + 22} y2={y1} style={{ stroke: 'var(--color-ink)' }} strokeWidth="2" />
        <polygon points={`${outX + 26},${y1} ${outX + 19},${y1 - 4.5} ${outX + 19},${y1 + 4.5}`} style={{ fill: 'var(--color-ink)' }} />
        <text x={outX + 30} y={y1 + 4} fontSize="12" style={{ fill: 'var(--color-ink)' }}>salida</text>
      </g>,
    );
  }
  return (
    <svg viewBox={`0 0 ${width} ${height}`} style={{ width: '100%', maxWidth: `${Math.round(width * 1.3)}px`, height: 'auto', display: 'block', margin: '0.4rem auto' }} role="img" aria-label={label}>
      {cells}
      {graph}
      {thread.length > 1 ? <polyline points={points} fill="none" style={{ stroke: 'var(--color-mark)' }} strokeWidth="4" strokeLinejoin="round" strokeLinecap="round" /> : null}
      {last ? <circle cx={last[0]} cy={last[1]} r="6.5" style={{ fill: 'var(--color-mark)', stroke: 'var(--color-surface)' }} strokeWidth="2" /> : null}
      {doors}
      {caption ? <text x={width / 2} y={height - 12} textAnchor="middle" fontSize="12" style={{ fill: 'var(--color-ink-soft)' }}>{caption}</text> : null}
    </svg>
  );
}

{/* Calls — the calls in progress, the first at the bottom: a frame per call, `depth` frames tall whatever it holds, so a walk's drawing keeps its size; the top one, the call that runs, in mark, and `flag` paints the frames of a call that should never have been made. File-local. */}

export function Calls({ items, depth, flag = [], label }) {
  const rowH = 24;
  const head = 18;
  const width = Math.max(110, 16 + Math.max(0, ...items.map((t) => t.length)) * 8.4);
  const height = head + depth * (rowH + 4) + 4;
  return (
    <svg viewBox={`0 0 ${width} ${height}`} style={{ width: '100%', maxWidth: `${Math.round(width * 1.3)}px`, height: 'auto', display: 'block', margin: '0.4rem auto' }} role="img" aria-label={label}>
      <text x={width / 2} y={12} textAnchor="middle" fontSize="11" style={{ fill: 'var(--color-ink-soft)' }}>pila de llamadas</text>
      {items.map((t, i) => {
        const y = height - (i + 1) * (rowH + 4);
        const top = i === items.length - 1;
        const bad = flag.includes(i);
        return (
          <g key={i}>
            <rect x={4} y={y} width={width - 8} height={rowH} rx="4" style={{ fill: bad ? 'var(--color-flag-soft)' : top ? 'var(--color-mark-soft)' : 'var(--color-surface)', stroke: bad ? 'var(--color-flag)' : top ? 'var(--color-mark)' : 'var(--color-ink-soft)' }} strokeWidth={top || bad ? 2 : 1.2} />
            <text x={width / 2} y={y + rowH / 2 + 4} textAnchor="middle" fontSize="12" fontWeight="700" fontFamily="var(--font-mono, monospace)" style={{ fill: 'var(--color-ink)' }}>{t}</text>
          </g>
        );
      })}
    </svg>
  );
}

{/* OutputBox — what a walk has printed or returned so far: a titled box with one row per value, `rows` rows tall whatever it holds, so the frame keeps its size; `fresh` outlines the last row, the one this step wrote. File-local. */}

export function OutputBox({ lines = [], rows = 3, head = 'salida', fresh = false, label }) {
  const rowH = 26;
  const pad = 10;
  const headH = 20;
  const width = Math.max(120, pad * 2 + Math.max(0, ...lines.map((l) => String(l).length)) * 9.6 + 16);
  const height = headH + rows * rowH + pad;
  return (
    <svg viewBox={`0 0 ${width} ${height}`} style={{ width: '100%', maxWidth: `${Math.round(width * 1.3)}px`, height: 'auto', display: 'block', margin: '0.4rem auto' }} role="img" aria-label={label}>
      <text x={pad} y={14} fontSize="11" fontWeight="700" letterSpacing="0.08em" style={{ fill: 'var(--color-ink-faint)' }}>{head.toUpperCase()}</text>
      <rect x={1} y={headH} width={width - 2} height={rows * rowH + pad - 2} rx="6" style={{ fill: 'var(--color-surface)', stroke: 'var(--color-rule-strong)' }} strokeWidth="1" />
      {lines.map((t, r) => {
        const y = headH + 4 + r * rowH;
        const hot = fresh && r === lines.length - 1;
        return (
          <g key={r}>
            {hot ? <rect x={pad - 4} y={y + 1} width={String(t).length * 9.6 + 8} height={rowH - 4} rx="4" style={{ fill: 'var(--color-mark-soft)', stroke: 'var(--color-mark)' }} strokeWidth="1.6" /> : null}
            <text x={pad} y={y + 18} fontSize="16" fontWeight="700" fontFamily="var(--font-mono, monospace)" style={{ fill: valueTone(String(t).split(' ').pop()) }}>{String(t)}</text>
          </g>
        );
      })}
    </svg>
  );
}

{/* valueTone — the colour of a value in a drawing: true in keep; false, ∞ and null in flag; nothing in faint; anything else in ink. */}

export function valueTone(t) {
  const v = String(t);
  if (v === 'true') return 'var(--color-keep)';
  if (v === 'false' || v === '∞' || v === 'null') return 'var(--color-flag)';
  if (v === '') return 'var(--color-ink-faint)';
  return 'var(--color-ink)';
}

}

<Slide title="El preorden en un grafo">

El preorden de un árbol visita un nodo y después recorre cada hijo con la
misma regla. Copiada a un grafo, la regla visita un vértice y después recorre
cada vecino con la misma regla. En un árbol termina, porque entre los hijos de
un nodo nunca está su padre. En un grafo, entre los vecinos de un vértice está
aquel desde el que se llegó: la regla vuelve por la misma arista y desde ahí
vuelve a avanzar, sin terminar nunca.

<Slide title="No volver al vértice anterior">

El arreglo tentador es recordar desde qué vértice se llegó, y no volver a
él. En un árbol basta: el único vecino de un nodo que el preorden ya recorrió
es su padre. En un grafo con un ciclo no basta: la regla da la vuelta al
ciclo y llega otra vez al primer vértice, ahora por otra arista, que no es la
de llegada. El problema no es la arista de vuelta: son los ciclos.

<Slide title="La tiza de Trémaux">

Al enrollar el hilo, Teseo no guarda nada de los pasillos que ya probó. En un
laberinto con un ciclo, alrededor de una columna, puede dar la vuelta, volver
a entrar por otro lado a un pasillo ya recorrido y seguir dando vueltas sin
fin. El método de Trémaux, que Édouard Lucas cuenta en 1882 en el primer tomo
de sus _Récréations mathématiques_, agrega una tiza: se marca cada lugar por
el que se pasa, y nunca se entra a uno marcado.

En un grafo, la tiza es un arreglo de booleanos con una casilla por vértice:
`marked[v]` dice si ya se pasó por `v`.

<Slide title="La regla de la búsqueda en profundidad">

{/* AdjMatrix — an adjacency matrix as Java holds it: `rows[v][w]` is the text of the cell in row v and column w ('true', 'false', a weight, '∞'), with the vertex numbers along the top and the left. A cell that holds an edge — anything but 'false', '∞' or '' — keeps a plain ground; its TEXT carries the meaning (`valueTone`): an edge — 'true' or a weight — in keep, no edge — 'false' or '∞' — in flag. The grid is one set of even lines, so every cell closes the same; `mark` outlines the cells [v, w] the slide talks about, on top. File-local, with AdjLists below: the two drawings of the implementations act. */}

export function AdjMatrix({ rows, mark = [], caption, label }) {
  const n = rows.length;
  const cw = 50;
  const ch = 30;
  const head = 26;
  const pad = 10;
  const gridW = head + n * cw;
  const width = Math.max(gridW + 2 * pad, caption ? caption.length * 6.6 + 24 : 0);
  const left = (width - gridW) / 2;
  const top = pad;
  const height = top + head + n * ch + (caption ? 34 : pad);
  const x0 = left + head;
  const y0 = top + head;
  const empty = (t) => t === 'false' || t === '∞' || t === '';
  const tone = (t) => (empty(t) ? valueTone(t) : 'var(--color-keep)');
  const parts = [];
  for (let v = 0; v < n; v++) {
    parts.push(<text key={`r${v}`} x={left + head / 2} y={y0 + v * ch + ch / 2 + 5} textAnchor="middle" fontSize="13" fontWeight="700" style={{ fill: 'var(--color-ink-soft)' }}>{v}</text>);
    parts.push(<text key={`c${v}`} x={x0 + v * cw + cw / 2} y={top + head / 2 + 5} textAnchor="middle" fontSize="13" fontWeight="700" style={{ fill: 'var(--color-ink-soft)' }}>{v}</text>);
    for (let w = 0; w < n; w++) {
      const t = String(rows[v][w]);
      parts.push(<text key={`t${v},${w}`} x={x0 + w * cw + cw / 2} y={y0 + v * ch + ch / 2 + 5} textAnchor="middle" fontSize="13" fontWeight="700" fontFamily="var(--font-mono, monospace)" style={{ fill: tone(t) }}>{t}</text>);
    }
  }
  const lines = [];
  for (let i = 0; i <= n; i++) {
    lines.push(<line key={`h${i}`} x1={x0} y1={y0 + i * ch} x2={x0 + n * cw} y2={y0 + i * ch} style={{ stroke: 'var(--color-ink-soft)' }} strokeWidth="1.4" strokeLinecap="square" />);
    lines.push(<line key={`v${i}`} x1={x0 + i * cw} y1={y0} x2={x0 + i * cw} y2={y0 + n * ch} style={{ stroke: 'var(--color-ink-soft)' }} strokeWidth="1.4" strokeLinecap="square" />);
  }
  return (
    <svg viewBox={`0 0 ${width} ${height}`} style={{ width: '100%', maxWidth: `${Math.round(width * 1.3)}px`, height: 'auto', display: 'block', margin: '0.4rem auto' }} role="img" aria-label={label}>
      <rect x={x0} y={y0} width={n * cw} height={n * ch} style={{ fill: 'var(--color-surface)' }} />
      {lines}
      {mark.map(([v, w]) => (
        <rect key={`m${v},${w}`} x={x0 + w * cw + 1.5} y={y0 + v * ch + 1.5} width={cw - 3} height={ch - 3} style={{ fill: 'var(--color-mark-soft)', stroke: 'var(--color-mark)' }} strokeWidth="3" />
      ))}
      {parts}
      {caption ? (
        <text x={width / 2} y={height - 12} textAnchor="middle" fontSize="12" style={{ fill: 'var(--color-ink-soft)' }}>{caption}</text>
      ) : null}
    </svg>
  );
}

{/* AdjLists — adjacency lists as Java holds them: one row per vertex, its number in a box, then the chips of its list in the order they were added. A chip's text is what the list stores: a neighbour, or a neighbour and a weight written `w · weight`, which draws the chip as the `Edge` Java keeps — three fields, `from` (the row's vertex), `to` and `weight`, each named small above its value. `keys` writes a name in each box instead of the number, for a map from names to their neighbours. `side` adds a column at the right with one value per vertex — an array the program fills by vertex, headed `sideHead` — and `sideMark` lists the vertices whose value it outlines. `minWidth` holds the lists' width from the first frame of a walk that fills them, so the drawing does not grow. `mark` lists the [vertex, position] chips the slide talks about. */}

export function AdjLists({ lists, keys, side, sideHead, sideMark = [], minWidth = 0, mark = [], caption, label }) {
  const weighted = lists.some((l) => l.some((t) => String(t).includes(' · ')));
  const rowH = weighted ? 46 : 36;
  const box = keys ? Math.max(30, ...keys.map((k) => String(k).length * 8 + 14)) : 30;
  const chipH = weighted ? 38 : 26;
  const gap = 8;
  const pad = 12;
  const fieldsOf = (v, t) => {
    const [to, weight] = String(t).split(' · ');
    return [['from', String(v)], ['to', to], ['weight', weight]];
  };
  const fieldW = ([name, value]) => Math.max(name.length * 6 + 12, value.length * 8 + 14);
  const chipW = (t, v) => (weighted ? fieldsOf(v, t).reduce((acc, f) => acc + fieldW(f), 0) : Math.max(32, String(t).length * 8 + 16));
  const rowW = (l, v) => box + 24 + l.reduce((acc, t) => acc + chipW(t, v) + gap, 0);
  const listsW = Math.max(...lists.map(rowW), box + 24 + 40, minWidth);
  const sideW = side ? Math.max(60, ...side.map((t) => String(t).length * 7.6 + 16), sideHead ? sideHead.length * 7.6 : 0) : 0;
  const innerW = listsW + (side ? 18 + sideW : 0);
  const top = pad + (sideHead ? 18 : 0);
  const width = Math.max(innerW + 2 * pad, caption ? caption.length * 6.6 + 24 : 0);
  const left = pad + (width - 2 * pad - innerW) / 2;
  const height = top + lists.length * rowH + (caption ? 30 : pad);
  const sideOn = new Set(sideMark);
  const marked = new Set(mark.map(([v, i]) => `${v},${i}`));
  return (
    <svg viewBox={`0 0 ${width} ${height}`} style={{ width: '100%', maxWidth: `${Math.round(width * 1.3)}px`, height: 'auto', display: 'block', margin: '0.4rem auto' }} role="img" aria-label={label}>
      {sideHead ? (
        <text x={left + listsW + 18 + sideW / 2} y={top - 6} textAnchor="middle" fontSize="12" fontWeight="700" fontFamily="var(--font-mono, monospace)" style={{ fill: 'var(--color-ink)' }}>{sideHead}</text>
      ) : null}
      {lists.map((l, v) => {
        const y = top + v * rowH;
        const mid = y + (weighted ? chipH : box) / 2;
        const boxY = mid - box / 2;
        const chipY = mid - chipH / 2;
        let x = left + box + 24;
        return (
          <g key={v}>
            <rect x={left} y={boxY} width={box} height={box} style={{ fill: 'var(--color-sunk)', stroke: 'var(--color-rule-strong)' }} strokeWidth="1" />
            <text x={left + box / 2} y={mid + 5} textAnchor="middle" fontSize="13" fontWeight="600" style={{ fill: 'var(--color-ink)' }}>{keys ? keys[v] : v}</text>
            <line x1={left + box} y1={mid} x2={left + box + 18} y2={mid} style={{ stroke: 'var(--color-rule-strong)' }} strokeWidth="1.3" />
            {l.map((t, i) => {
              const w = chipW(t, v);
              const hot = marked.has(`${v},${i}`);
              const cx = x;
              x += w + gap;
              const frame = (
                <rect x={cx} y={chipY} width={w} height={chipH} rx="6" style={{ fill: hot ? 'var(--color-mark-soft)' : 'var(--color-surface)', stroke: hot ? 'var(--color-mark)' : 'var(--color-rule-strong)' }} strokeWidth={hot ? 2.2 : 1} />
              );
              if (!weighted) {
                return (
                  <g key={i}>
                    {frame}
                    <text x={cx + w / 2} y={mid + 4} textAnchor="middle" fontSize="12" fontFamily="var(--font-mono, monospace)" style={{ fill: 'var(--color-ink)' }}>{t}</text>
                  </g>
                );
              }
              let fx = cx;
              return (
                <g key={i}>
                  {frame}
                  {fieldsOf(v, t).map((f, k) => {
                    const fw = fieldW(f);
                    const at = fx;
                    fx += fw;
                    return (
                      <g key={k}>
                        {k > 0 ? <line x1={at} y1={chipY + 4} x2={at} y2={chipY + chipH - 4} style={{ stroke: 'var(--color-rule)' }} strokeWidth="1" /> : null}
                        <text x={at + fw / 2} y={chipY + 12} textAnchor="middle" fontSize="9" fontFamily="var(--font-mono, monospace)" style={{ fill: 'var(--color-ink-soft)' }}>{f[0]}</text>
                        <text x={at + fw / 2} y={chipY + 29} textAnchor="middle" fontSize="13" fontWeight="700" fontFamily="var(--font-mono, monospace)" style={{ fill: 'var(--color-ink)' }}>{f[1]}</text>
                      </g>
                    );
                  })}
                </g>
              );
            })}
            {side ? (
              <g>
                <rect x={left + listsW + 18} y={mid - 13} width={sideW} height={26} style={{ fill: sideOn.has(v) ? 'var(--color-mark-soft)' : 'var(--color-sunk)', stroke: sideOn.has(v) ? 'var(--color-mark)' : 'var(--color-rule-strong)' }} strokeWidth={sideOn.has(v) ? 2.2 : 1} />
                <text x={left + listsW + 18 + sideW / 2} y={mid + 4} textAnchor="middle" fontSize="12" fontWeight="700" fontFamily="var(--font-mono, monospace)" style={{ fill: valueTone(side[v]) }}>{side[v]}</text>
              </g>
            ) : null}
          </g>
        );
      })}
      {caption ? (
        <text x={width / 2} y={height - 10} textAnchor="middle" fontSize="12" style={{ fill: 'var(--color-ink-soft)' }}>{caption}</text>
      ) : null}
    </svg>
  );
}

{/* ArrayRows — the arrays, lists and maps a program keeps beside its graph, one per row: its Java name on the left, then a cell per entry with the index above it (`head` overrides the indices: the keys of a map). A row whose `cells` is null keeps its place blank, `size` cells wide: an array the program has not created yet, so every frame of a walk has the same size; `cell` is the least width of a cell and `cols` the least number of cells, for the same reason. `mark` outlines the [row, cell] entries the frame talks about. */}

export function ArrayRows({ rows, mark = [], cell = 34, cols = 1, caption, label }) {
  const pad = 10;
  const headH = 16;
  const ch = 28;
  const gapY = 10;
  const nameW = Math.max(...rows.map((r) => r.name.length * 8 + 14));
  const cw = Math.max(cell, ...rows.flatMap((r) => [...(r.cells ?? []), ...(r.head ?? [])].map((t) => String(t).length * 7.6 + 14)));
  const innerW = nameW + Math.max(cols, ...rows.map((r) => (r.cells ? r.cells.length : r.size ?? 0))) * cw;
  const width = Math.max(innerW + 2 * pad, caption ? caption.length * 6.6 + 24 : 0);
  const left = (width - innerW) / 2;
  const rowH = headH + ch + gapY;
  const height = pad + rows.length * rowH + (caption ? 24 : 0);
  const marked = new Set(mark.map(([r, i]) => `${r},${i}`));
  return (
    <svg viewBox={`0 0 ${width} ${height}`} style={{ width: '100%', maxWidth: `${Math.round(width * 1.3)}px`, height: 'auto', display: 'block', margin: '0.4rem auto' }} role="img" aria-label={label}>
      {rows.map((row, r) => {
        const y = pad + r * rowH + headH;
        return (
          <g key={r}>
            {row.cells === null ? null : (
              <text x={left + nameW - 10} y={y + ch / 2 + 5} textAnchor="end" fontSize="13" fontWeight="700" fontFamily="var(--font-mono, monospace)" style={{ fill: 'var(--color-ink)' }}>{row.name}</text>
            )}
            {(row.cells ?? []).map((t, i) => {
              const x = left + nameW + i * cw;
              return (
                <g key={i}>
                  <text x={x + cw / 2} y={y - 4} textAnchor="middle" fontSize="11" style={{ fill: 'var(--color-ink-soft)' }}>{row.head ? row.head[i] : i}</text>
                  <rect x={x} y={y} width={cw} height={ch} style={{ fill: 'var(--color-surface)', stroke: 'var(--color-ink-soft)' }} strokeWidth="1.4" />
                </g>
              );
            })}
            {(row.cells ?? []).map((t, i) =>
              marked.has(`${r},${i}`) ? <rect key={`m${i}`} x={left + nameW + i * cw + 1.5} y={y + 1.5} width={cw - 3} height={ch - 3} style={{ fill: 'var(--color-mark-soft)', stroke: 'var(--color-mark)' }} strokeWidth="3" /> : null,
            )}
            {(row.cells ?? []).map((t, i) => (
              <text key={`t${i}`} x={left + nameW + i * cw + cw / 2} y={y + ch / 2 + 4} textAnchor="middle" fontSize="12" fontWeight="700" fontFamily="var(--font-mono, monospace)" style={{ fill: valueTone(t) }}>{String(t)}</text>
            ))}
          </g>
        );
      })}
      {caption ? (
        <text x={width / 2} y={height - 8} textAnchor="middle" fontSize="12" style={{ fill: 'var(--color-ink-soft)' }}>{caption}</text>
      ) : null}
    </svg>
  );
}

`hasPathTo(t)` retorna `marked[t]`. `prev` dice por dónde: desde `t`, seguir

después lo saca de la pila hacia una lista, que queda de `s` a `t`; si `t` no

<Slide title="La pila de llamadas en un laberinto grande">

Cada llamada a `dfs` en curso ocupa un marco en la pila de llamadas de Java,
y la búsqueda tiene en curso una llamada por cada celda del hilo. En un
laberinto sin muros, la búsqueda baja por la primera columna, sube por la
segunda y sigue así, serpenteando, hasta pasar por todas las celdas sin volver
nunca: el hilo llega a tener todas las celdas a la vez.

En un laberinto de $$1000 \times 1000$$ eso es un millón de llamadas en
curso, y la pila de Java no da para tanto. Medido en un JDK 21, con la pila que
trae por defecto, `dfs` lanza `StackOverflowError` con unas 17 000 llamadas en
curso; un laberinto de $$100 \times 100$$ sin muros, que llega a 10 000,
todavía termina. El número exacto cambia de una máquina a otra, pero queda
lejos del millón.

<Slide title="Marcar al apilar">

Sin recursión, el hilo se guarda en una pila propia, un `Stack` que el
programa maneja. La idea tentadora copia el recorrido por niveles de un árbol,
que encola cada hijo una sola vez: marcar cada vecino al apilarlo, para no
apilarlo dos veces. Llega a los mismos vértices, pero no en profundidad. Un
vecino marcado al apilarlo queda marcado sin que la búsqueda haya pasado por
él, y otro vértice que lo mira lo salta: «marcado» deja de decir «visitado» y
pasa a decir «visto». El orden de visita salta, además, entre vértices sin
arista entre ellos: Teseo no podría caminarlo.

<GraphWalk
  beside

  code={`private void dfs(Graph g, int s) {
    Stack<Integer> stack = new Stack<>();
    marked[s] = true;
    stack.push(s);
    while (!stack.empty()) {
        int v = stack.pop();
        for (int w : g.adj(v)) {
            if (!marked[w]) {
                marked[w] = true;
                prev[w] = v;
                stack.push(w);
            }
        }
    }
}`}

<Slide title="El código de la búsqueda en profundidad iterativa">

La versión correcta marca al sacar: saca un vértice; si ya está marcado lo
descarta, y si no, lo marca y apila cada vecino sin marcar, anotando su
`prev`. Como el último apilado sale primero, visita los vecinos en el orden
inverso al de la recursiva, pero siempre avanza desde el último vértice que
alcanzó: sigue siendo en profundidad.

**Con las listas cuesta $$\Theta(V + E)$$.** Las listas suman $$2E$$ entradas,
una por cada extremo de arista, y se pasa por cada uno de los $$V$$ vértices.

ningún programa que mire cada arista puede hacerlo en menos.

<Slide title="El costo de la búsqueda en profundidad">

La búsqueda marca cada vértice que alcanza una sola vez, y lee sus vecinos una
sola vez, al marcarlo. Cuando alcanza todo el grafo, recorre los vecinos de
cada vértice una vez, lo mismo que `degrees(g)`:

- **Con las listas, $$\Theta(V + E)$$.** Las listas suman $$2E$$ entradas,
  y cada una se lee una vez.
- **Con la matriz, $$\Theta(V^2)$$.** Cada `adj(v)` recorre una fila
  completa de $$V$$ casillas.
- **Memoria, $$\Theta(V)$$** para `marked` y `prev`. La recursiva tiene
  además hasta $$V$$ llamadas en curso en la pila de llamadas; la iterativa
  apila un vértice cada vez que lo ve sin marcar, y su pila llega a tener
  hasta $$2E + 1$$ entradas.

Si no alcanza todo el grafo, cuesta lo que mide la parte que alcanza.

</Slide>

<Slide title="La distancia en un laberinto">

camino que da no es necesariamente el más corto, y no dice cuál es la
distancia. Para encontrarla hace falta recorrer el grafo en otro orden.

<Slide title="Las capas de distancia">

Las celdas a distancia 1 de la entrada son sus vecinas. Las que están a
distancia 2 son las vecinas de esas que todavía no tienen distancia, y así:
cada **capa** se arma con los vecinos nuevos de la capa anterior. La
distancia de una celda es el número de su capa. Para llegar a la salida por
el camino más corto hay que recorrer el laberinto capa por capa: primero
toda la capa 1, después toda la 2.

El recorrido por niveles de un árbol visita la raíz, después sus hijos,

<Slide title="La regla de la búsqueda en anchura">

La regla marca al encolar: **sacar el vértice del frente de la cola, y por
cada vecino sin marcar, marcarlo, darle la distancia del vértice más uno,
anotar su `prev` y encolarlo.** Un vértice marcado no vuelve a entrar, así
que cada uno entra a la cola una sola vez, y la distancia que recibe es la de
su capa. Avanza capa por capa, a lo ancho: por eso se llama **búsqueda en
anchura**, en inglés _breadth-first search_ (BFS).

<Slide title="La invariante de la cola">

La búsqueda en anchura mantiene una invariante: **la cola tiene a lo más dos
capas seguidas, primero vértices de una capa $$d$$ y detrás vértices de la
capa $$d + 1$$.** Al sacar un vértice de la capa $$d$$, sus vecinos nuevos van
al final, a la capa $$d + 1$$, y la invariante sigue valiendo. Por eso los
vértices salen en orden de distancia. Cuando un vértice `w` se ve por primera
vez, desde `v`, ya salieron todos los vértices más cercanos que `v` y ninguno
lo vio: no hay un camino más corto hasta `w`, y `dist[w] = dist[v] + 1` es
definitiva.

<Slide title="El costo de la búsqueda en anchura">

Cada vértice que se alcanza entra a la cola una sola vez, y sus vecinos se
leen una sola vez, al sacarlo. Es el mismo recorrido de todos los vecinos de
la búsqueda en profundidad:

- **Con las listas, $$\Theta(V + E)$$.** Las listas suman $$2E$$ entradas,
  y cada una se lee una vez.
- **Con la matriz, $$\Theta(V^2)$$.** Cada `adj(v)` recorre una fila
  completa.
- **Memoria, $$\Theta(V)$$**: `marked`, `dist`, `prev` y la cola, que
  nunca tiene más de $$V$$ vértices.

La distancia que calcula cuenta aristas. Es la respuesta cuando las aristas
no tienen peso, o cuando todas pesan lo mismo.

<Slide title="Grafo bipartito">

Un grafo es **bipartito** si sus vértices se pueden repartir en dos grupos
sin aristas dentro de cada uno: ¿se pueden repartir en dos grupos sin
conflictos dentro de cada uno? Por ejemplo, armar dos equipos sin rivales
adentro. La búsqueda en anchura da un reparto: las capas pares a un grupo y
las impares al otro. Una arista entre dos vértices de la misma capa es un
conflicto, y entonces no hay reparto posible: cierra un ciclo de largo
impar.

<Slide title="La bolsa">

La búsqueda en profundidad iterativa y la búsqueda en anchura son el mismo
ciclo: sacar un vértice de la **bolsa** de pendientes y meter en ella sus
vecinos sin marcar. Cambian dos cosas. La bolsa: una pila, que saca el último
que entró, o una cola, que saca el primero. Y el momento de marcar: la
iterativa marca al sacar, y la de anchura al meter, que es lo que le da a cada
vértice una distancia definitiva.

<Slide title="Un orden que no respeta los prerrequisitos">

Una malla curricular dice qué ramos hay que aprobar antes de cada uno: una
flecha de un ramo a otro si el primero es prerrequisito del segundo. Ninguno
de los dos recorridos dice en qué orden tomarlos. Basta que la lista de un
ramo nombre primero a uno que debe ir después: la búsqueda en profundidad lo
visita antes que su prerrequisito, y la búsqueda en anchura también.
