## Problem

The pedagogical content of "Estructuras de Datos en Java" must be written into the new content pipeline. This is not a code task — it's the actual textbook content (text + visualizers + executable Java examples + slide markers for presentation mode), authored in MDX, committed to the repo.

The topic structure follows `docs/course-graph.md` (51 topics across 14 groups, topologically ordered).

## Goals

- Each MDX section combines: theory text, embedded visualizer widgets, executable Java code examples, deliberate slide markers (`<Slide>`, `<BookOnly>`, `<PresentationOnly>`, `<TeacherNote>`).
- All sections render without error (smoke test that opens each section and verifies rendering).
- Course outline reflects `docs/course-graph.md` topological order.
- Slide markers applied with intention (not auto-h2 fallback for every section — explicit pedagogical choice of what's in book vs presentation).
- At minimum: enough chapters written to actually teach the first semester.

## Non-goals

- Custom illustrations / polished visual design (post-MVP).
- Translation / i18n (curriculum is in Spanish, single language for now).
- Solving content for chapters beyond what's needed for August.
- Interactive course planning UI — content lives as MDX files committed to repo.
