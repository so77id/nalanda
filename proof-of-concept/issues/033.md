## Problem

S2.3 introduced routes but each route renders flat — no shared chrome, no way to see "where am I in the book". A real digital textbook needs a persistent TOC sidebar (chapter and section index, current location highlighted) and breadcrumbs (`Course > Chapter > Section`). This shell wraps every content route and uses React Router v6's `<Outlet/>` to host the route-specific body.

## Goals

- Define a `<CourseShell/>` layout component that wraps section routes. It renders:
  - Top app bar (reuse `Appbar.jsx`), with breadcrumbs (`Course / Chapter / Section title`) on the left.
  - Left sidebar: TOC tree showing all chapters and sections of the current course. The current section is highlighted. Clicking any section navigates.
  - Main area: `<Outlet/>` — where `SectionPage` (or `CourseOverview`) renders.
- Refactor the router so course routes are nested under `CourseShell`:
  ```
  / (LandingPage)
  /courses/:slug (CourseShell -> CourseOverview)
  /courses/:slug/:chapter/:section (CourseShell -> SectionPage)
  ```
- Breadcrumbs read from URL params + section frontmatter (title comes from frontmatter, not slug).
- Sidebar is collapsible (small screens) — toggle button in app bar.
- Sidebar state (open/closed) persisted in `localStorage` so it stays consistent across navigations.
- Mobile responsive: sidebar becomes an overlay drawer < 768px.

## Non-goals

- Cross-course navigation in the sidebar (only the current course's TOC).
- Search inside TOC (future).
- Reading progress indicators per section (future, requires admin domain).
- Floating TOC for the current section's headings (per-page mini-TOC). Out of scope; can be a future polish ticket.
- Animations beyond a basic show/hide transition.

## Design

**Approach:** Standard nested-route layout with `<Outlet/>`. The shell fetches the course's section list via `listSections(slug)` (from S2.2) and renders the TOC. URL params (`useParams()`) tell the shell which section is active so it can highlight the right node.

**Architecture decisions consumed:**
- **C** — React Router v6 nested routes via `<Outlet/>`.
- **X** — Material Domain: the shell is all about content presentation, no auth.

**Files to create / modify:**
- `src/routes/CourseShell.jsx` — the layout component.
- `src/routes/TocSidebar.jsx` — TOC tree component. Props: `sections` (array from `listSections`), `currentSlug`, `currentChapter`, `currentSection`. Renders nested list.
- `src/routes/Breadcrumbs.jsx` — small component reading from `useParams()` + frontmatter map.
- `src/routes/router.jsx` — refactor to nest course routes under `CourseShell`.
- `src/chrome/Appbar.jsx` — extend to host breadcrumbs + sidebar-toggle button (or wrap). Existing usage in `Presentation.jsx` is preserved.
- `src/styles/*.css` (or Tailwind) — sidebar styling. Use Tailwind classes inline per CLAUDE.md conventions.
- `smoke-test-routing.mjs` (extended) or new `smoke-test-toc.mjs` — asserts sidebar exists, current section is highlighted, breadcrumbs show right text, clicking a TOC entry navigates.

**TOC data shape (returned by `listSections(slug)`):**

```js
[
  { frontmatter: { title, order, chapter }, path: 'courses/<slug>/<chapter>/<section>.mdx' },
  ...
]
```

The TOC component groups by `chapter`, sorts by `order` within each chapter, sorts chapters alphabetically (or by a chapter-level metadata file — out of scope here, alphabetic suffices for fase 1).

**Mobile breakpoint:** Tailwind `md` (768px). Below: sidebar is hidden by default, opens as overlay on toggle.

**Layout grid:**
```
+--------- Appbar (breadcrumbs + theme + toggles) -----------+
| Toc     | Outlet (SectionPage / CourseOverview)           |
| (~256px)| (flex-1)                                         |
+---------+-------------------------------------------------+
```

## Acceptance criteria

- [ ] AC1: Visiting `/courses/<slug>/<chapter>/<section>` shows the app bar, breadcrumbs, sidebar (with TOC), and section content.
- [ ] AC2: Breadcrumbs read: `<Course title> / <Chapter title or slug> / <Section title>`.
- [ ] AC3: TOC sidebar lists all sections grouped by chapter. Current section is visually highlighted (e.g. `aria-current="page"` + bold + accent color).
- [ ] AC4: Clicking a section in the TOC navigates to that section.
- [ ] AC5: Sidebar toggle button collapses/expands the sidebar. State persists across page reloads via `localStorage`.
- [ ] AC6: At width < 768px, sidebar is hidden by default; toggling opens it as an overlay drawer with backdrop.
- [ ] AC7: `npm run lint && npm run build` pass.
- [ ] AC8: Smoke test (`smoke-test-toc.mjs` or extended `smoke-test-routing.mjs`) passes.
- [ ] AC9: Manual verification on Chrome (desktop + responsive 375px) shows correct layout + interactions.
- [ ] AC10: `/legacy` route still renders the POC unchanged (no shell wrapping it).
