## Problem

Other professors want to use Nalanda for their own courses. We need an admin dashboard to manage users and roles, a professor dashboard to manage their courses/students/sessions, and the ability to create courses + course_versions from a UI rather than seed scripts.

## Goals

- Admin dashboard: list users, change roles, view global metrics.
- Professor dashboard: list their courses, view enrolled students, see past sessions, see submissions.
- Create/edit `courses` + `course_versions` from UI (not seed).
- Role-based route guards.

## Non-goals

- Course inheritance / forking (that's E10).
- In-browser content editor (that's E11).
- Billing, multi-tenant isolation at infrastructure level (post-roadmap).
